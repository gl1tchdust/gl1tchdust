# Shivam Mahajan

Application security engineer. API security, authorization testing, DevSecOps pipelines. Pune, India.

## Repositories

- [devsecops-pipeline-lab](https://github.com/gl1tchdust/devsecops-pipeline-lab) - a security toolchain in CI with custom Semgrep rules for BOLA, BFLA and mass assignment, scored against hand-labelled ground truth. Measured precision decides which rules are allowed to fail a build.
- [api-authz-testing-playbook](https://github.com/gl1tchdust/api-authz-testing-playbook) - runnable test cases for OWASP API authorization flaws. A differential probe replays each case as owner, peer and anonymous; every request example is a verbatim capture from a live target.
- [newman-oauth-refresh](https://github.com/gl1tchdust/newman-oauth-refresh) - OAuth2 token refresh for Newman collection runs, which Postman's CLI does not do. Proactive for JWTs, reactive on 401 for opaque tokens, never written to disk. Published on [npm](https://www.npmjs.com/package/newman-oauth-refresh).
- [agent-tool-authz](https://github.com/gl1tchdust/agent-tool-authz) - authorization for LLM agent tool calls. A detector that checks whether an MCP server's tools do what they declare, measured at precision 0.800 over 289 tools in four real codebases, and a gate that enforces policy over them.
